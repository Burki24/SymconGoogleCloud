# Unveröffentlicht

## Neu

- **Google Cloud Konto** verlinkt im Formular eine Anleitung zum benötigten
  Find-Hub-Zugriffstoken.
- **Google Cloud Konto** ruft die Find-Hub-Geräteliste direkt bei Google ab,
  wenn ein gültiges Zugriffstoken vorliegt. Bei Fehlern bleibt die zuletzt
  erhaltene Liste verfügbar.
- **Google Cloud Konto** stellt einen lokalen Gerätestand für spätere
  Standortabnehmer bereit. Das Konto zeigt den Status der Google-Anmeldung
  im Konfigurationsformular an.
