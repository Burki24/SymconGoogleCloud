SymconGoogleCloud ist eine eigenständige Bibliothek für Google-Dienste in
Symcon. Das [Google Cloud Konto](Google%20Cloud%20Account/README.md) kann
mit einem vorhandenen Find-Hub-Zugriffstoken eine Geräteliste direkt bei Google
abrufen und lokal bereitstellen. Anmeldung, Standortabruf und die Anzeige in
OpenWoIst folgen in weiteren Ausbaustufen.

## Voraussetzungen und Einrichtung

Vorausgesetzt werden Symcon ab Version 9.0 und PHP 8.5 mit cURL. Sobald die Bibliothek
in der Modulverwaltung eingebunden ist, lässt sich eine Instanz
**Google Cloud Konto** anlegen. Ihr Formular zeigt den aktuellen
Funktionsumfang an.
