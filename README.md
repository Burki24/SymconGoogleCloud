SymconGoogleCloud ist eine eigenständige Bibliothek für Google-Dienste in
Symcon. Der erste Entwicklungsstand enthält das
[Google Cloud Konto](Google%20Cloud%20Account/README.md) mit einem lokalen
Gerätecache. Die Verbindung zu Google und die Anzeige in OpenWoIst folgen
in den nächsten Ausbaustufen.

## Voraussetzungen und Einrichtung

Vorausgesetzt werden Symcon ab Version 9.0 und PHP 8.5. Sobald die Bibliothek
in der Modulverwaltung eingebunden ist, lässt sich eine Instanz
**Google Cloud Konto** anlegen. Ihr Formular zeigt den aktuellen
Funktionsumfang an.
